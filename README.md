# MyWikiResearch

Навичка для AI-агента [`wiki-interest/`](wiki-interest/): досліджує інтерес до тем у різних
мовних розділах Wikipedia за статистикою переглядів і робить графіки та PDF-звіти на одну
сторінку. Опис, встановлення, методологія перевірки та план розвитку — у
[`wiki-interest/README.md`](wiki-interest/README.md).
