# MyWikiResearch

Навичка для AI-агента [`wiki-interest/`](wiki-interest/). Вона досліджує, як змінюється
інтерес до тем у різних мовних розділах Wikipedia, і робить графіки та PDF-звіти на одну
сторінку. Навичка допомагає вирішити, які теми розвивати і якими мовами запускати продукт.
Для кожного висновку вона показує, наскільки йому можна довіряти і чому.

Методологія, перевірка та план розвитку описані в [`wiki-interest/README.md`](wiki-interest/README.md).

## Що потрібно

- **Python 3.10+** і **git**.
- **Claude Code**, щоб працювати з навичкою через агента. Для нього потрібен Node.js 18+:
  ```bash
  npm install -g @anthropic-ai/claude-code
  claude            # під час першого запуску увійдіть в акаунт, потім /exit
  ```
- Доступ до `wikimedia.org`, `*.wikipedia.org` і `www.wikidata.org` (звідти беруться дані).

## Встановлення

```bash
git clone https://github.com/lizakolot12/MyWikiResearch.git
cd MyWikiResearch
./setup.sh          # Windows: setup.cmd
```

`setup.sh` робить таке:
1. копіює навичку в `~/.claude/skills/wiki-interest`, тож вона доступна в усіх проєктах;
2. створює в ній `.venv` і ставить залежності (системний Python не змінюється);
3. запускає `doctor`, який перевіряє залежності й доступ до Wikimedia API.

Наприкінці має бути `"pageviews_api": "ok"` і `"wikidata_api": "ok"`.

Повторний запуск `./setup.sh` оновлює навичку і зберігає вже завантажені дані.

Додаткові параметри (їх можна передати й самому `setup.sh`):

| Параметр | Що робить |
|---|---|
| `--project DIR` | встановити навичку лише для одного проєкту: `DIR/.claude/skills/wiki-interest` |
| `--link` | символічне посилання замість копії: зміни в репозиторії діють одразу (для розробки) |
| `--dest DIR` | встановити в теку навичок іншого агента |
| `--zip FILE.zip` | зібрати архів для завантаження в claude.ai (Settings → Capabilities → Skills) |
| `--no-doctor` | не запускати фінальну перевірку |

## Запуск

Відкрийте Claude Code на моделі Haiku відразу після встановлення:

```bash
./setup.sh claude haiku
./setup.sh claude haiku "Чи зростає інтерес до астрономії в українській Вікіпедії?"
```

Замість `haiku` можна вказати `sonnet`, `opus` або повний ідентифікатор моделі.

Якщо навичку вже встановлено, Claude Code можна запускати з будь-якої теки:

```bash
mkdir -p ~/wiki-test && cd ~/wiki-test
claude --model haiku
```

Графіки й PDF-звіти з'являються в теці, з якої запущено Claude Code, у підтеці
`wiki-interest-output/`.

## Як переконатися, що навичка працює

1. **Claude бачить навичку.** Наберіть у Claude Code `/` і знайдіть у списку `wiki-interest`.
2. **Поставте питання.** Щоб навичка точно спрацювала, почніть повідомлення з `/wiki-interest`:
   ```
   /wiki-interest Ми думаємо додати курс з астрономії до освітнього застосунку. Чи зростає інтерес до цієї теми в україномовній Wikipedia, і наскільки цьому зростанню можна довіряти?
   ```
   Можна писати й без `/wiki-interest`. Тоді агент сам вирішує, чи використати навичку,
   за її описом.
3. **Агент викликає скрипт навички.** У стрічці дій має бути команда на кшталт
   `python …/wiki-interest/scripts/wiki_interest.py analyze --topics "Astronomy" --langs uk`.
   Коли Claude попросить дозволу її виконати, дозвольте.
4. **У відповіді є:**
   - вердикт («зростає», «повільно зростає», «стабільно»…) і тренд у відсотках на рік;
   - рівень довіри до висновку з причинами;
   - застереження, що перегляди Вікіпедії показують інтерес, а не готовність платити;
   - шлях до графіка.
5. **Уточнення працюють у тій самій розмові.** Спробуйте «Додай польську і чеську» (дані
   беруться з кешу, тож відповідь буде швидшою) або «Зроби PDF-звіт».

Інші приклади запитів:
- «Порівняй зростання інтересу до інтервального голодування в польськомовній та
  чеськомовній Wikipedia за останні два роки.»
- «Ми створюємо застосунок для вивчення мов. Порівняй інтерес до вивчення англійської в
  польській, чеській, українській та німецькій Wikipedia і підготуй короткий PDF-звіт.»

## Перевірка без агента

Скрипт можна запустити напряму, щоб переконатися, що дані завантажуються:

```bash
S=~/.claude/skills/wiki-interest/scripts/wiki_interest.py
python $S doctor
python $S analyze --topics "Astronomy" --langs uk,pl --months 24
python $S show --series uk
python $S report --title "Тест" --summary "Перевірка" --rec "Перевірка" --out test.pdf
```

## Тести

```bash
cd wiki-interest
python -m venv .venv && source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -r requirements-dev.txt
python -m pytest -q tests
```

Автоматична перевірка з агентом на Claude Haiku 4.5 (витрачає кредити акаунта Claude):

```bash
python evals/run_evals.py --model claude-haiku-4-5-20251001 --judge claude-sonnet-5
```

## Якщо щось не так

| Проблема | Що зробити |
|---|---|
| `wiki-interest` немає у списку `/` | запустіть `./setup.sh` ще раз і перезапустіть Claude Code |
| `doctor` показує `api_error` | немає доступу до `wikimedia.org`: перевірте мережу, VPN або проксі |
| агент пише власний код або шукає в інтернеті | почніть повідомлення з `/wiki-interest` |
| `No module named numpy` | запустіть `./setup.sh` ще раз: він створить `.venv` із залежностями |
| будь-яка інша помилка | запустіть `python $S doctor` і збережіть вивід команди, що впала |
